The flow

  1. Export from ChatGPT. Open Settings, then Data controls, then Export data. ChatGPT emails you a download link that expires after about a day. Download the .zip. (Menu wording may differ slightly.)
  2. Convert with Claude. Upload the .zip, or the conversations.json inside it, to Claude and paste the prompt below. Claude gives you Markdown files, one per chat or per project, to download.
  3. Read here. Save the .md files on your phone, tap Open .md file, and pick one to read it as a chat. Open one file at a time.
Convert this ChatGPT export into Markdown files, one .md file per chat. Group chats by project if the export shows projects. Start each file with the chat title as a # heading, then label every message on its own line as **You:** or **ChatGPT:**, with a blank line between messages. Keep code blocks and lists as they are. Give me all files in one zip. If the export is large, start with the 20 most recent chats.

Using the reader

  • Your messages appear on the right and the AI's on the left.
  • Use Search to find text, and Copy on any code block.
  • Tap Edit to change, delete or Swap side (moves a message to the other speaker, for when a speaker was mixed up). Download saves a new .md copy; your original file is never changed. Edits are labeled, and saved copies say they were edited. Please only edit your own chats.
  • On Android, open this page in Chrome, then choose the menu (⋮) and Install app to add it to your home screen.

Your chat stays with you

  • The file is read inside your browser. It is never uploaded, and this page has no server that could receive it.
  • Step 2 above is separate: uploading your export to Claude sends it to Claude. This reader never does.
  • Your chats are never saved or tracked. Reload or close the tab and the chat is gone. Only your style and mode choice is remembered, on this device.
  • After your first visit the app's own files (the page, icons, fonts and two small libraries) stay on your device so it opens without internet. Your chats are never part of that.
